# bytesint.xyz - OSINT Platform

Cutting-edge OSINT intelligence platform and breach lookup dashboard built with React 18, Vite, TypeScript, and Tailwind CSS.

## 🚀 Quick Start

### 1. Requirements & Prerequisites
- **Node.js** (v18+ or v22+ recommended)
- **Python** 3.10+ (for API/backend services, optional)

### 2. Install Dependencies

**Frontend (Node.js):**
```bash
npm install
```

**Backend (Python - Optional):**
```bash
pip install -r requirements.txt
```

### 3. Run Development Server

Double-click `start.bat` or run:

```bash
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Production Build

```bash
npm run build
npm start
```

## 🛠️ Tech Stack
- **Frontend Framework:** React 18 + TypeScript + Vite
- **Styling & UI:** Tailwind CSS, Lucide / Phosphor / FontAwesome Icons via Iconify
- **Smooth Scroll:** Lenis
- **Interactive Shaders:** `@paper-design/shaders-react`
- **Typography:** Satoshi (Fontshare)
